Архитектура приложения

Приложение построено на принципах Onion Architecture (Луковая архитектура) на Go:

  • Domain Layer - бизнес-логика и сущности
  • Application Layer - use cases и сценарии использования
  • Infrastructure Layer - SQLite БД, JWT аутентификация
  • Presentation Layer - REST API и фронтенд

Особенности: SQLite БД с персистентным хранением, JWT токены, мультипользовательская система, Dependency Injection, REST принципы, Swagger документация, Go + Gin + GORM
