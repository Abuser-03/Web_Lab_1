Архитектура приложения

Приложение построено на принципах Onion Architecture (Луковая архитектура) на Go:

  • Domain Layer - бизнес-логика и сущности
  • Application Layer - use cases и сценарии использования
  • Infrastructure Layer - thread-safe хранилище данных в памяти
  • Presentation Layer - REST API и фронтенд

Особенности: In-Memory хранилище (максимум 50 записей), Dependency Injection, REST принципы, Swagger документация, Go + Gin
